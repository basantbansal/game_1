# Bhutiya Ghar

Bhutiya Ghar is a small atmospheric horror game created in Godot using GDScript. It is a personal project inspired by spooky haunted-house experiences, tension, mystery, and survival gameplay.

Play the game here:
https://basanthunter.itch.io/bhutiya-ghar

## About the Project

This game was built in my free time as a passion project. The goal was to create a compact, eerie experience with a creepy environment, simple controls, and a strong horror atmosphere.

The project uses Godot and GDScript, making it easy to edit, expand, and improve over time.

## Features

- Creepy haunted-house atmosphere
- Simple and intuitive controls
- Exploration-based gameplay
- Horror-focused mood and tension
- Built with Godot and GDScript
- Easy to extend for future updates

## Gameplay

Explore the environment, stay alert, and survive the eerie experience. The game focuses on creating fear through atmosphere, sound, and exploration rather than complex systems.

## Controls

- W, A, S, D: Move
- Shift: Run
- Mouse: Look around
- E: Interact
- Esc: Pause / menu

## Requirements

- Godot 4.x or the compatible project version
- A desktop PC or laptop
- Optional: headphones for a more immersive horror experience

## How to Run

1. Download or clone this repository.
2. Open the project in Godot.
3. Import the project if prompted.
4. Press F5 or click Run to start the game.

## Project Structure

The exact folder layout may vary depending on the project version, but the repository generally contains:

- `Scenes/`: Main game scenes
- `Scripts/`: GDScript logic
- `Assets/`: Art, audio, and other resources
- `UI/`: Menus and interface elements

## Development Notes

This project is a personal creative build and is continuously open to improvements. It can be used as a base for experimentation, learning, or expanding into a larger game.
